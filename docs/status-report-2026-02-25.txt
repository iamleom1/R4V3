What gets the app to ~90% (practical checklist)

1. Runtime QA sweep (highest priority)
- Test all new flows on real devices/accounts (photos, location, matching radius, unread/read persistence)
- Permission denial/retry cases (camera roll, location)
- Offline/slow network/error states

2. Realtime messaging + read state
- Subscribe to new messages/read-state changes via Supabase Realtime
- Eliminate manual refresh dependency
- Add delivery/send retry UX

3. Filter/business-rule enforcement consistency
- Ensure client filters (music/group/sober) are enforced server-side or clearly marked as UI-only
- Add canonical backend query path for all match filtering

4. Profile/media hardening
- Image size/type validation
- Compression/resizing before upload
- Limits/quotas and better replacement/delete recovery
- Safer storage cleanup on partial failures

5. Location/privacy hardening
- Clear consent copy and fallback UX
- Timestamp freshness rules (stale location handling)
- Coarse-area display only (avoid oversharing exact location)
- Server-side "must have location for local matching" enforcement everywhere matching is queried

6. End-to-end tests + regression checks
- Smoke tests for auth/onboarding/profile/match/chat
- Migration validation on staging
- DB policy tests (RLS access expectations)

7. Ops / Launch readiness
- Crash reporting (e.g., Sentry)
- Analytics funnel events
- Logging/alerting for Supabase errors
- App store privacy disclosures and release configs
- Backup/rollback plan for migrations

8. Moderation and trust tools
- Reporting/block flows fully wired
- Basic moderation queue tooling/internal process
- Abuse/rate limit protections for messaging/swipes
